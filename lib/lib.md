# lib/

Data access, rules and helpers for the app. The pure files have no React imports, so Node's test runner can run them directly.

## Files

| File                                       | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api.ts`                                   | The `Api` interface (`feed`, `categories`, `numbersToKnow`, `appConfig`) and `getApi()`, which picks mock or Supabase from env vars. Returns an error instead of guessing when the config is wrong.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `api.mock.ts`                              | Mock API over the sample files in `contract/fixtures/`. Sets `sample: true`, so the app shows the SAMPLE DATA banner. 200 ms fake delay.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `api.supabase.ts`                          | Calls the Supabase `api` schema with plain `fetch` (no supabase-js; signed-in reads add `Authorization: Bearer <token>`): `POST /rest/v1/rpc/feed` with `Content-Profile: api`, and `GET` on `app_config`, `categories`, `numbers_to_know` with `Accept-Profile: api`. Sends only the `apikey` header (publishable key). Errors never include the key.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `config.ts`                                | Reads `EXPO_PUBLIC_API_MODE`, `EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY`. Mock is the default. Supabase mode with a missing or placeholder URL/key, or a secret key, is an error. Also `APP_NAME`, page size, column width.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `types.ts`                                 | Runtime guards for API data (types come from `contract/types.ts`). Drops cards with an unknown kind, no headline, or no source link; never crashes the feed.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `labels.ts`                                | Which trust labels a card shows: disclaimer on every card, AI label when `ai.generated`, FRED notice on FRED data cards, the "how this card was made" text, and the CC BY-SA credit for Wikipedia cards (license URL from the `cc_by_sa` notice, constant as fallback). Fallback strings if `app_config` is missing.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `format.ts`                                | Relative time, headline clamp (90 chars), change text with glyph and word (never colour alone), screen-reader labels, category names (API names win; fallbacks carry the renames Business, Government, Money and the new World, Science & Space, Recalls & Safety), event names (incl. World, Recall, Science), host name of a URL.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `feedLogic.ts`                             | Feed reducer (append, dedupe, reset on filter change, ignore late responses) and the mock pager (offset cursor, Top/Latest order, category filter).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `theme.ts`                                 | Design tokens: light palette (the default, from the design files) and a matching dark palette, font family names (Newsreader, Instrument Sans), spacing, radii, the 1024 px wide breakpoint.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `seriesCopy.ts`                            | One plain-language line per macro series for the Numbers screen (UI copy, not data).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `account.ts`                               | Accounts: one `AccountApi` interface, two implementations. Supabase: Auth (GoTrue) over REST (`/auth/v1/signup`, `token?grant_type=password`, `refresh_token`, `logout`) and the account RPCs (`get_prefs`, `set_prefs`, `track`, `feed_for_you`, `delete_my_data`, `delete_account`) with the user's Bearer token. Also password reset (`POST /auth/v1/recover?redirect_to=…`, answered the same way for any email; friendly message on the mailer's 429), recovery from the emailed link, change password and change email (`PUT /auth/v1/user`), and delete account (clears the local session). If a token refresh is rejected, the session is cleared and `takeSignOutReason()` gives "Please sign in again." once. The session is kept in localStorage on web and refreshed a minute before expiry. Mock: in-memory accounts over the sample cards, so sample mode works with no back end. `ACCOUNT_RPC` holds the RPC names and arguments, typed against `contract/account.ts`. |
| `accountLogic.ts`                          | Pure rules: onboarding gate (server `onboarded` flag or skipped on this device), topic toggles, like/dislike/clear, `my_reaction`, once-per-session view tracking, the mock For you order.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `session.ts`                               | Parses GoTrue sessions, refresh timing, email/password checks, friendly auth error messages (never echoes tokens).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `storage.ts`                               | localStorage on web (with try/catch), memory elsewhere.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `accountContext.tsx`                       | React state for the signed-in user: prefs, reactions (optimistic, rolled back on error), view and open-source tracking, delete my data.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `openUrl.ts`                               | Opens an original source; tells the account layer so a signed-in open counts as `open_source`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `useFeed.ts`, `useTheme.ts`, `appData.tsx` | React glue: feed hook, palette and wide-layout hooks, shared `app_config` + categories context.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

## Env vars

| Name                                   | Values                                         |
| -------------------------------------- | ---------------------------------------------- |
| `EXPO_PUBLIC_API_MODE`                 | `mock` (default) or `supabase`                 |
| `EXPO_PUBLIC_SUPABASE_URL`             | `https://<project>.supabase.co`                |
| `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | the publishable key only, never the secret key |

`EXPO_PUBLIC_*` values are baked in at build time: change `.env`, then rebuild.

## Tests

```bash
node --experimental-strip-types --test "lib/__tests__/*.test.ts"
```

Covers labels (no card kind renders without the disclaimer), formatting, guards, the feed reducer and mock paging, the Supabase request shape and error handling, the sample fixtures, and a scan for secret keys in `app/`, `components/` and `lib/`. On Node 23.6+ the flag is optional. A "module type" warning per file is harmless.
