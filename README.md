# Blurb app (working name)

Short, plain-language business and market news "blurbs" in a swipe feed, for busy people. Web, iOS and Android from one Expo codebase, with a Supabase back end.

Informational only. Not investment advice.

## Status

Planning done. Build has not started.

## Stack

- App: Expo (React Native) + Expo Router, for iOS, Android and web
- Back end: Supabase (Postgres, Auth, Edge Functions, pg_cron)
- Web hosting: Cloudflare Pages
