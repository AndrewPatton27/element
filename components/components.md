# components/

UI pieces used by the screens in `app/`. Plain React Native (works on web through react-native-web). Colours, fonts and sizes come from `lib/theme.ts`. No images, no stock prices.

| File                   | What it shows                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Shell.tsx`            | Page frame for every screen. Phones: content plus a bottom tab bar (Feed, Brief, Search, Following, Me; Numbers and About are linked from the Me page). Wide web (≥ 1024 px, design `docs/design/web/Web-Final.dc.html`): no bottom nav; a 64 px top bar (wordmark, Trending / Latest / For you, Numbers link, Sign in or Account pill), the 44 px Numbers strip, then a body (max 1360 px) of optional `left` column (180 px), the main column and optional `aside` (280-340 px), plus a floating About pill bottom left. Scroll screens (Numbers, About, Account, Sign in) get the same bar and strip with a centered 760 px column. On non-feed screens the tabs go back to the feed (`/?tab=…`). Shows the SAMPLE DATA banner in mock mode. Also exports `Wordmark`.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `NumbersTicker.tsx`    | Wide web, every screen: the looping "Numbers to know" strip under the top bar (requestAnimationFrame, no Reanimated; pauses on hover; with reduced motion it stops and scrolls by hand). Each item shows value, change and agency and opens the original series. Uses `useNumbers` from `NumbersPanel.tsx`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `WideAside.tsx`        | Wide right column: `useAsideData(api)` loads `api.topStories()` / `api.numberTrends()` (a failure leaves that section empty; pass `enabled` false and it makes no calls). The trends slideshow also pauses while the pointer is over it or focus is inside. "Top stories · last week" numbered list (click opens the card's More detail) and "Trends · 12 weeks" chart card (prev / next, dots, auto-rotate every 7 s, off with reduced motion, agency source line). Chart math in `trendChart.ts` (tested in `lib/__tests__/trendChart.test.ts`). |
| `BriefChrome.tsx`      | Brief screen chrome: `BriefTabs` (Daily / Weekly underline tabs, 56 px in the phone header, 48 px row on wide), `BriefMeta` ("Generated 5 h ago · last 24 h" plus a 44 px Refresh button) and `BriefEmpty` ("not ready yet" or "everything is hidden", with Try again / Open the feed). |

| `FeedPager.tsx`        | One card per screen: `FlatList` with paging and snap. The card's footer hint is the Next button; on web ↑/↓, PageUp/PageDown and j/k also move. Tells the card whether to draw the next card's edge (`peek`, not on the last card). Switches to compact type below 640 px of page height.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

Wide cards (`wide`): 48 px headline, 20 px detail line, an Agency / Type / Published row on summary cards, and a "tight" mode (card under 660 px tall) that shrinks padding and type so the source row, labels and disclaimer always fit. Save / Share / Report buttons from the design are not built (no such features yet).

Rules kept here: every card shows the disclaimer; the AI label text comes from `app_config`, not from the card; direction is never shown by colour alone; every source links to the original URL from the sources sheet.

Accessibility note: react-native-web ignores `accessibilityState` and `accessibilityHint`, so selected or pressed states use `aria-selected`, `aria-checked`, `aria-pressed` and `aria-disabled`, and hints are part of the label.


Card footer: the disclaimer is built once and placed by `disclaimerPlacement` (`lib/labels.ts`), so it renders exactly once whether or not `onReact` is passed (a non-function `onReact` counts as absent). `Disclaimer` falls back to the built-in wording if its text is empty.
