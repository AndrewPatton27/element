# components/

UI pieces used by the screens in `app/`. Plain React Native (works on web through react-native-web). Colours, fonts and sizes come from `lib/theme.ts`. No images, no stock prices.

| File                   | What it shows                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Shell.tsx`            | Page frame for every screen. Phones: content plus a bottom nav (Feed, Numbers, About, Account / Sign in). Wide web (≥ 1024 px): left rail with the wordmark, the same nav and "Signed in as …", the content column, and an optional right rail. Shows the SAMPLE DATA banner in mock mode. Also exports `Wordmark`.                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `FeedPager.tsx`        | One card per screen: `FlatList` with paging and snap. The card's footer hint is the Next button; on web ↑/↓, PageUp/PageDown and j/k also move. Draws the edge of the next card under the current one. Switches to compact type below 640 px of page height.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `Card.tsx`             | A feed card: badge (Summary, New data, From the source), category · event · time, headline (Newsreader), numbers panel on data cards, body, tickers (symbols only), source row, the Wikipedia credit line on CC BY-SA cards, AI label, then the footer. Signed in: "More" / "Less" buttons (👍/👎 icons, check mark and selected state when pressed; pressing again undoes it), with the disclaimer on its own line. Guests: the disclaimer sits in the footer. Only the middle part can shrink, so source row, labels and disclaimer are always visible. Tapping the text opens the detail sheet ("<headline>. Opens more detail"); cards with detail also show "More detail ›". Headline and body end with "…" rather than being cut. |
| `DataCard.tsx`         | `DataFacts`: the big-number panel. One number at 64 px; two or more side by side. Change shown as ▲/▼/■ glyph plus a word (colour is extra), period or date, agency (`source_short`), and the FRED notice.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `SourceChip.tsx`       | `SourceRow`: primary outlet and document plus the source count; opens the sources sheet. `openUrl` helper.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `SourcesSheet.tsx`     | "Where this came from": every source with a link to the original, "How this card was made" (AI, template or data), an "Open the source" button and the disclaimer.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `NumbersPanel.tsx`     | "Numbers to know" rows. `full` (Numbers screen, with a plain-language line per number) and `compact` (desktop right rail). Rows open the original data series.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `Labels.tsx`           | `AiLabel`, `Disclaimer`, `ShareAlikeLine` ('Adapted from Wikipedia ("…") · CC BY-SA 4.0': the credit links to the article, the mark links to the license). Strings come from `lib/labels.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `CategoryChips.tsx`    | "All" plus the categories from the API; scrolls sideways on phones, wraps on wide screens.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `SortToggle.tsx`       | Feed tabs (underline style): Trending (API mode `top`), Latest, and For you when signed in.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `Icons.tsx`            | SVG line icons (react-native-svg) with path data from the design files: feed, bar chart (Numbers, New data), sparkle, link, external link, chevron, close, building, person (Account); info, document, thumbs and eye / eye-off drawn in the same style.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `States.tsx`           | Loading, empty and error states, the full-screen configuration error, and a shared `Button`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `SampleBanner.tsx`     | "SAMPLE DATA" strip shown on every screen when the app runs on sample fixtures.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `TopicPicker.tsx`      | Multi-select topic chips for onboarding and the Account screen (check mark + accessibility checkbox state).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `PasswordField.tsx`    | Password input with the show/hide eye (`Show password` / `Hide password`, checked state), `autoComplete` `current-password` or `new-password` so browser password managers work, and `hideSignal` to hide the text again after a submit. `fieldStyles` keeps the email inputs matching.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `DetailSheet.tsx`      | "More detail", opened by tapping a card: bottom sheet on phones, centered panel on wide screens. Headline, key points, paragraphs (or the summary with "More detail isn't available for this card yet."), the numbers panel on data cards, sources, Wikipedia credit, AI label, disclaimer. Focus is trapped; Escape / back closes.                                                                                                                                                                                                                                                                                                                                                                                                     |
| `SourceList.tsx`       | The source rows shared by the sources sheet and the detail sheet (link to each original, "and N more outlets", CC BY-SA license link).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `TopicStatePicker.tsx` | Account → Your favorite topics: Favorite / Normal / Hide per topic ("Favorite" is stored as followed) (radio buttons with `aria-checked`, ✓ on the chosen one).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `CardMenu.tsx`         | The card's "⋯" options (signed in): "Hide <Topic> topics".                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `UndoToast.tsx`        | "<Topic> topics hidden." with Undo, shown for 5 s.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

Rules kept here: every card shows the disclaimer; the AI label text comes from `app_config`, not from the card; direction is never shown by colour alone; every source links to the original URL from the sources sheet.

Accessibility note: react-native-web ignores `accessibilityState` and `accessibilityHint`, so selected or pressed states use `aria-selected`, `aria-checked`, `aria-pressed` and `aria-disabled`, and hints are part of the label.
